# AgentDE Homebrew tap

```bash
brew install --cask agentde/tap/agentde
```

Installs [AgentDE](https://github.com/AgentDE/agentde), a native macOS home for terminal agents. On first launch its Workstream panel offers to connect Claude Code and Codex; or from a terminal:

```bash
/Applications/AgentDE.app/Contents/Resources/register-workstream.sh --yes
```

Update with `brew upgrade --cask agentde`.
